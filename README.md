# Candidate Searcher — быстрый поиск по базе резюме в Excel

🤔 Проблема: Вы устали вручную пролистывать сотни строк в Excel, чтобы найти телефон кандидата из нужного города? Постоянно переключаетесь между таблицей и блокнотом, теряя время на простом копировании контактов?

💡Решение: Небольшая утилита командной строки (CLI) на Python, которая превращает статичную таблицу candidates.xlsx в интерактивную базу данных. Никаких сложных интерфейсов или баз данных — только ваш терминал и мгновенные ответы.

## ⚙️Как это работает:

✔️Мгновенный фильтр по городу. Введите команду город Москва, и скрипт моментально выведет аккуратную таблицу со всеми кандидатами из столицы, их ФИО, телефонами и зарплатными ожиданиями.
✔️Умный поиск по фамилии. Команда фамилия Иванов найдет первого подходящего человека, покажет его полное досье и автоматически скопирует номер телефона в буфер обмена вашего компьютера. Больше не нужно выделять цифры мышкой — один ввод в терминале, и номер готов к вставке в Telegram или WhatsApp.
✔️Терпимость к ошибкам ввода. Программа сама приводит названия колонок и ваши команды к единому регистру. Ей всё равно, написано ли в вашем Excel «ФИО», «Ф.И.О.» или «Город проживания».
✔️Безопасная работа с данными. Скрипт корректно обрабатывает пустые ячейки и сообщает, если нужный столбец случайно назван иначе (например, «Имя» вместо «ФИО»), подсказывая, как это исправить.

## 🖥️Для кого этот инструмент:

✔️Для HR-менеджеров и рекрутеров, которые ведут базу кандидатов в простых Excel-таблицах.
✔️Для руководителей отделов продаж, работающих со списками клиентов.
✔️Для всех, кто хочет автоматизировать рутину без перехода на тяжелые CRM-системы.
Технические детали:

🐍Язык: Python 3.
➡️ Зависимости: pandas, openpyxl (для чтения .xlsx) и встроенная библиотека tkinter для работы с буфером обмена.
➡️ Запускается одной командой из терминала после установки зависимостей (pip install pandas openpyxl).
➡️ Никаких графических окон, лишних кликов и тормозов. Только чистый код, скорость вашей клавиатуры и полный контроль над базой данных прямо в консоли.
